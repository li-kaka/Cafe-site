# CAFÉ de PARIS

A desktop single-page café website created as a school assignment, bringing together the café’s atmosphere, menu and location information.

## Production

Wireframe / Design / Coding

## Tools

Figma / Visual Studio Code

## Technologies

HTML / CSS / JavaScript

## Overview

CAFÉ de PARIS is a desktop single-page café website developed from a school assignment brief for a restaurant in Nishi-Shinjuku.

The site introduces the café’s atmosphere, news, menu and access information through large photography and a clear browsing flow.

## Purpose

The original brief asked for a new top page that would improve awareness of the café and attract customers beyond its existing magazine advertising.

I expanded the brief into a single-page site that communicates the brand atmosphere while helping visitors quickly find menu and location information.

## Target

Men and women in their 20s and 30s who are looking for an approachable café or casual restaurant in the Nishi-Shinjuku area.

The site also supports visitors who want to check the café’s food, prices, opening information and location before visiting.

## Information Design

The content is organized as a single-page journey from the main visual to NEWS, ABOUT US, MENU and ACCESS.

Anchor navigation and smooth scrolling connect each section, while menu photographs, prices, shop information and an embedded map make the practical information easy to locate.

## Design

The visual direction follows the assignment’s request for a fashionable, bright and approachable café image.

Red and blue brand colors, large food photography, generous whitespace and an asymmetrical menu layout create a lively editorial feel. A branded loading screen and scroll-based reveal effects add movement while keeping the desktop experience clear and engaging.

## Features

- Branded loading screen displayed when the page loads.
- Single-page layout featuring NEWS, ABOUT US, MENU and ACCESS.
- Scroll-based reveal effects using `IntersectionObserver`.
- Smooth scrolling for in-page anchor links.
- Menu photographs and prices, shop information and an embedded Google Map.
